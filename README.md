# S. R. Mohan Raj | Portfolio

Exact reproduction of [mohanraj-web.vercel.app](https://mohanraj-web.vercel.app/).

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local dev server
npm run dev

# 3. Build for production
npm run build
```

## 🛠 Tech Stack
- **Framework**: React 18 with Vite
- **Styling**: Tailwind CSS
- **Motion / Intro Animation**: GSAP (`gsap`)
- **Icons**: Lucide React
- **Assets**: High-resolution cutout profile photo
